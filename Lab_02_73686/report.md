# Neural Network Report

**Objective:** To understand the basic concepts of neural networks.

**Forward Propagation:** The model processes input data and produces an output.

**Loss Function:** Measures the difference between the predicted and actual output.

**Backpropagation:** Calculates how the weights should change to reduce errors.

**Optimization:** Updates the weights to minimize the loss.

**Prediction Phase:** The trained model uses new data to make predictions.

**Conclusion:** Neural networks learn from data by reducing errors and updating their weights.
